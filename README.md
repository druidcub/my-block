# 小小方塊世界

適合 5 歲小孩與大人一起玩的 Minecraft 風格 3D 積木遊戲，由一隻不到一格高的立體像素企鵝帶你探索與創作。本遊戲為獨立創作，並非 Mojang 或 Microsoft 官方 Minecraft。

## 開始玩

雙擊 `開始遊戲.bat`，或用 Chrome / Edge 開啟 `index.html`。不必安裝套件、不需要網路，也沒有廣告或付費。

## 操作

| 動作 | 操作 |
| --- | --- |
| 走路 | 方向鍵、WASD，或左下角箭頭 |
| 看四周 | 按住遊戲畫面拖曳，上下左右皆可；企鵝停著時可轉動相機看牠的正面 |
| 企鵝 / 第一人稱 | 右側「第一人稱 / 看企鵝」或 F，預設從企鵝後方看世界 |
| 拉近 / 拉遠 | 滑鼠滾輪或右側 ＋ / −；企鵝視角改變跟隨距離，第一人稱縮放視野，上帝視角調整觀看高度 |
| 音效 / 背景音樂 | 右上 ♪ / ♫ 分別開關，音量可在右上或遊戲說明調整 |
| 微調準心 | 在畫面中央附近移動滑鼠，準心會跟著偏移；放置與拆除都依準心瞄準的位置 |
| 放積木 | 對準附近的積木表面，按「＋ 放積木」、E 或輕點畫面 |
| 拿掉積木 | 對準積木，按「− 拿掉」、Q 或滑鼠右鍵 |
| 選積木 | 下方積木箱，或數字鍵 1–8 |
| 積木分類 | 積木箱上方「彩色 / 建築 / 自然 / 趣味」，數字鍵對應目前分類中的積木 |
| 選取同款素材 | 準心指向積木後按 R，自動選取那種素材與分類 |
| 切換區域 | 左上角「探索區域」選單，各區域的作品分開保存 |
| 重力 / 飄浮 | Shift 或右側模式按鈕：按一下開啟重力，再按一下回到飄浮；會記住選擇 |
| 重力模式跳躍 | 空白鍵或「跳一下」：按一下跳躍，放開再連按可在空中持續往上跳；按住只跳一次 |
| 飄浮模式飛行 | 按住空白鍵 /「飛高」，按 C /「飛低」下降；放開就停在目前高度 |
| 快速落下 | 重力模式會自行落地；C /「落下」可中止上升並往下落 |
| 上帝視角 | 右側「工具」中的「上帝視角」，從高處看作品；再按「回到原位」還原位置、方向和準心 |
| 復原 | 右上方「復原」，或 Z（目前遊戲階段最多保留 150 個動作） |
| 回起點 | 「工具」中的「回小屋 / 回起點」 |
| 成就與統計 | 點左側「小小建築師」展開 / 收合；三項任務完成後自動收合 |
| 手把選單 | 右上 🎮、P 或手把 Menu；可切換區域、操作工具和設定手把 |

以淡黃色十字準心瞄準；選中的方塊有粗黃色亮框和深色外緣。準心可以在畫面中央附近偏移，拖曳畫面仍可轉頭。可操作範圍為 24 格。網頁內已停用瀏覽器預設右鍵選單，右鍵可直接拆除積木。

新玩家預設飄浮模式，放開飛行按鈕就停在目前高度。Shift 是重力開關，按住不會反覆切換；開啟重力後會持續落向地面或屋頂，落地後重力仍啟用，走出平台也會再落下。空白鍵每次新按下都會跳躍，空中連按可持續向上；只按住不會自動連跳。再次按 Shift 會立即切回飄浮並停止上升 / 下落。重力、跳躍與飛行都不會造成傷害。

企鵝模型身高約 0.8 格，包含動畫仍低於 0.82 格；玩家碰撞身高為 0.82 格，眼睛離腳底 0.72 格，可以走進一格高的通道。上下移動都會檢查經過的地面、屋頂與天花板，避免跳躍穿過方塊；若原本飛得太高，可用 C 或「飛低」降到通道高度。重力與手把偏好不會因切換區域或「新世界」而改變。

上帝視角為作品觀看模式，可以拖曳轉頭；移動與放置、拆除按鈕暫停，按「回到原位」即可繼續玩。小島底層受保護，所有積木皆為無限供應。世界範圍 40 × 40 格，高度 40 格；飛行上限為眼睛高度 38 格。

## 適合小孩的設計

- 繁體中文、大型按鈕、滑鼠 / 鍵盤 / 觸控操作。
- 和平的白天世界：沒有怪物、戰鬥、飢餓、死亡或時間壓力。
- 二十二種積木，分成彩色、建築、自然、趣味四類；包含紅磚、窗框、白磚、柏油、沙地、火山岩、青綠與會閃動的安全岩漿，以及三種不同顏色、有倒數數字的定時炸彈。
- 七個區域各有獨立的作品、建造次數、星星、選用素材和遊玩位置。
- 三個簡單任務：放第一塊積木、累計放八塊、使用三種積木。星星是鼓勵性獎勵，沒有強制流程。
- 任務清單可手動展開 / 收合，全部完成時會自動縮成摘要。摘要仍顯示本區域「蓋了、拿掉、炸開」的累計操作；復原不會扣除已經做過的次數。手動拿掉與炸開分開計數，連鎖爆炸的每個方塊只計一次。各區域統計分開保存，舊存檔沒有的新統計從零開始。
- 常用的重力切換、復原和放 / 拆保留大按鈕；視角、上帝視角、回起點、新世界和縮放收入「工具」，減少畫面遮擋。手把操作時會顯示 RT / LT 提示並收起螢幕方向按鈕；使用鍵鼠或觸控會切回原提示。
- 放磚、拆磚、爆炸、腳步、拍翅、落地與星星獎勵有不同音效；輕柔的原創背景音樂可離線循環播放。兩者分開開關，預設皆關閉。
- 「新世界」會先顯示目前區域名稱，只重建這個區域；其他區域的作品與星星都會保留。

## 小企鵝與相機

企鵝是實際存在世界中的立體方塊模型，包含黑色身體、白色臉與肚子、橘色喙與腳、可動翅膀。模型的最高點在每種動作中都低於一格，保留走進一格高通道的能力。

- 走路時兩腳交替，身體輕輕左右搖擺，朝實際移動方向平順轉身；停下後逐漸回到站立姿勢。
- 飛高時快速拍翅，翅膀展開到水平以上再向下拍動，身體稍微前傾；空中懸停時張翅拍動並輕輕浮動。
- 飛低與自由落體時張開翅膀；落地短暫蹲一下再站好。動畫不會改變碰撞大小或推動玩家。
- 預設第三人稱相機會跟隨企鵝；相機遇到牆壁、屋頂或狹窄通道會自動縮近，太近時暫時隱藏角色，保持畫面與準心清楚。
- 滾輪縮放有平滑過渡。建造、拆除與黃框皆使用同一相機與準心，不會因視角切換或縮放而瞄錯位置。
- 需要更精準地蓋磚時，可按 F 切回第一人稱。手機也有視角切換與縮放按鈕。

## 聲音與音樂

右上 **♪ 音效** 與 **♫ 背景音樂** 各自開關，可只開音效或只開音樂。新玩家預設皆關閉；設定會記住，下次按「開始玩」時才播放。

音效包含放磚的輕敲、拆磚的碎裂、炸彈的低沉爆破、最後三秒倒數提示、腳步、拍翅、下降、落地、選素材、復原及星星獎勵。連續腳步與拍翅有播放間隔，避免每個畫面都重複出聲。音量可用右上滑桿調整；手機可開啟說明找到音量滑桿。

背景音樂為本遊戲原創的兩段輕柔旋律，使用 Web Audio 合成鈴音與低音循環，不使用外部音樂檔、不需網路。合成器限制音量並經過動態壓縮。說明、重建確認視窗、背景分頁或視窗失去焦點時會暫停，回來再繼續；關閉開關會停止已排程的聲音。若瀏覽器不支援音訊，會提醒並繼續遊戲。

## Steam Controller 與 joystick

使用瀏覽器 Gamepad API，預設操作配置為 Steam Controller，也支援瀏覽器辨識為 `standard` 的一般手把。Steam Input 可以把控制器轉成一般手把 / XInput、滑鼠或鍵盤輸入，參考 [Valve 的手把模擬說明](https://partner.steamgames.com/doc/features/steam_controller/steam_input_gamepad_emulation_bestpractices?l=english&language=english)。

Steam Controller 請先把開啟遊戲的 Chrome / Edge 加入 Steam 的「非 Steam 遊戲」，從 Steam 啟動瀏覽器，並使用一般手把配置。初代的右觸控板需映射為右搖桿，有右搖桿的款式可直接使用。若使用鍵鼠配置，依本遊戲的 Space、Shift、E、Q、F、Z、P 等按鍵映射也能操作。遊戲不會更改 Steam 的全域設定。

瀏覽器通常要等玩家按一下手把按鍵才顯示連線；辨識後再按 A 可開始遊戲。右上 🎮 會顯示連線狀態，可開啟手把選單。預設操作如下：

| 手把操作 | 動作 |
| --- | --- |
| 左搖桿 | 走路，保留慢推慢走；斜走不會更快 |
| 右搖桿 / 右觸控板 | 轉頭與準心瞄準 |
| A | 飄浮模式按住飛高；重力模式按一下跳躍，放開再連按可飛高 |
| B | 切換重力；在選單中則返回，不會切換重力 |
| RT / LT | 放積木 / 拿掉；按住可慢速連續操作 |
| X / Y | 復原 / 切換企鵝與第一人稱 |
| LB / RB | 上一塊 / 下一塊素材 |
| 方向鍵左 / 右 | 切換積木分類 |
| 方向鍵上 / 下 | 拉近 / 拉遠 |
| L3 / R3 | 選取準心指向素材 / 飛低或落下 |
| View | 上帝視角 / 回到原位 |
| Menu | 手把選單 / 繼續玩 |

在手把選單中，方向鍵上下移動焦點，左右調整選項，A 選擇，B 返回。區域選單可先用左右預覽，A 才前往該區域；「新世界」仍會先出現確認畫面，預設焦點為取消。選單、背景分頁與離開視窗會暫停移動、重力及炸彈倒數。

「給大人」設定可調整轉頭速度、防飄移範圍與非標準手把的轉頭軸。非標準手把不會直接觸發遊戲動作；確認按鍵排列符合操作表後，可明確勾選使用非標準配置，或透過 Steam Input 重新映射。連線、換手把或關閉選單時，原本按住的按鍵必須放開再按，避免誤放、誤拆和誤跳。

## 七個區域

| 區域 | 可以玩什麼 |
| --- | --- |
| 小屋世界 | 保留原本的小屋、樹木、池塘和積木小動物，適合蓋花園、陽台 |
| 道路街景 | 十字路口、斑馬線、人行道、商店、車子和路燈，適合蓋公車站或自己的商店 |
| 火山口 | 火山岩山體、發亮的岩漿池與岩漿河、木造觀景平台；岩漿不會傷害玩家，適合造橋和探險 |
| 平坦草地 | 整片高度一致、沒有建築或樹木的草地，適合從零開始自由建造 |
| 鐵達尼號 | 大船、四座煙囪、木甲板、船艙、救生艇、碼頭與積木冰山，適合探索船艙、改造大船 |
| 汽車世界 | 橢圓賽道、終點拱門、停車場、車庫與不同顏色及大小的車子，適合自己蓋車；車子是可改造的積木模型 |
| 台北 101 | 八段層疊的青綠塔身、塔尖、商場入口、廣場與周邊建築，適合飛到高處探索；為積木風格簡化場景 |

切換區域會立即保存剛才的作品，再載入另一個區域。切回時會還原素材與位置。復原紀錄在這次遊戲期間也按區域分開；重新開啟遊戲後不保留復原紀錄。

## 定時炸彈

在積木箱切到「趣味」，選炸彈，按 E 或「放積木」。三款皆倒數十秒，方塊每一面直接顯示 **10 → 1** 及爆炸範圍，十秒後炸開以它為中心的球形範圍，有短暫彩色粒子與可選的輕柔音效。玩家不會受傷或被推開，底層仍受保護。

| 炸彈 | 顏色 | 球形爆炸半徑 |
| --- | --- | --- |
| 炸彈 2 格 | 紅色 | 2 格（原本款式） |
| 炸彈 5 格 | 紫色 | 5 格 |
| 炸彈 10 格 | 藍色 | 10 格 |

爆炸範圍內的其他炸彈會立即一起爆炸，不必等倒數結束。每顆以自己的位置和半徑擴大爆炸範圍，能引爆更遠的炸彈；連鎖只發生在目前區域。

- 倒數期間按 Q 拿掉炸彈，或復原放置，就能取消。
- 一整串連鎖爆炸算一個動作，按一次「復原」或 Z 就能還原整串爆炸移除的積木與所有炸彈；未被引爆的炸彈保留原本倒數。
- 復原後的炸彈顯示「停」，不會自行倒數；拿掉再重新放下才重新倒數。停止的炸彈仍可被另一顆炸彈連鎖引爆。
- 說明、重建確認視窗、背景分頁，以及未開始遊戲時暫停倒數。切換區域會保留原區域的剩餘秒數，回去才繼續。
- 關閉或重新整理遊戲也會保存剩餘秒數；下次開始玩才繼續，不會在關閉期間炸掉作品。
- 新世界只清除目前區域的炸彈，其他區域的作品與倒數不受影響。

## 存檔

每次放置、拿掉或復原會自動儲存到目前瀏覽器的 localStorage。七個區域使用不同鍵名：`little-block-world-v2:cottage`、`little-block-world-v2:street`、`little-block-world-v2:volcano`、`little-block-world-v2:meadow`、`little-block-world-v2:titanic`、`little-block-world-v2:cars`、`little-block-world-v2:taipei101`。`little-block-world-area-v2` 記住最後選擇的區域。`little-block-world-settings-v1` 另外記住視角、縮放距離、重力、音效、音樂、音量與手把偏好，重建區域不會清除這些偏好。重新開啟同一位置的遊戲，可繼續建造。存檔不會傳上網。

舊版 `little-block-world-v1` 作品會自動轉移到「小屋世界」，舊鍵保留作為備份。其他區域不會讀取這份舊存檔；小屋重建後也不會重新載入舊作品。

**請持續使用同一瀏覽器、同一檔案位置。** 換瀏覽器、移動檔案、使用無痕模式、清除瀏覽器資料或停用網站儲存，都可能讓原本作品無法載入。「新世界」只覆蓋目前區域的存檔。

若瀏覽器拒絕儲存，畫面會提醒；這次遊戲期間仍會在記憶體中保留各區域作品，可以往返切換，但關閉或重新整理後這些未成功存檔的修改會消失。

## 技術

HTML + CSS + 原生 JavaScript / WebGL；無外部函式庫、無網路字型、無建置流程。瀏覽器必須支援 WebGL。若顯示不了 3D，請更新 Chrome / Edge 並啟用硬體加速。

檔案：`index.html`（介面）、`style.css`（樣式）、`game.js`（世界生成、渲染、操作和存檔）、`penguin.js`（角色模型與動畫幾何）、`audio.js`（音效與原創音樂合成）、`controller.js`（手把讀取、防飄移和按鍵狀態）。

## 開發驗證

已安裝 Node.js 的開發者，可以執行 `node tests/game.test.cjs`、`node tests/audio.test.cjs` 與 `node tests/controller.test.cjs`。測試不需要安裝套件，涵蓋重力切換、單次與空中連跳、低天花板與平台落地、碰撞、獨立存檔與統計、成就收合、區域切換、舊存檔轉移、重建隔離、儲存失敗、三種炸彈計時與連鎖復原、企鵝動畫高度、相機避障、縮放瞄準一致性、音訊排程，以及模擬手把的移動、轉頭、建造、素材切換、選單、熱插拔、防飄移與按鍵保護。WebGL 與手機版面另以瀏覽器實測；自動手把測試使用模擬輸入，不代替真實 Steam Controller 的連線驗證。

本遊戲的探索與無限素材方向參考 [Minecraft 創造模式](https://www.minecraft.net/en-us/article/creative-vs-survival-mode)與[不同地形的探索](https://www.minecraft.net/en-us/article/exploring-minecraft)，保留適合幼童的和平玩法。
